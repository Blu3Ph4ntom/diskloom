Desktop app

Scan, sort, inspect, delete.

The DiskLoom app keeps cleanup work on one screen: drive shortcuts, path search, expandable folders, size and allocated-size columns, and Recycle Bin deletion.

It uses direct NTFS metadata scanning for supported Windows volumes and fallback traversal for folders or locations that need normal directory walking.

Install

One installer for the app and CLI.

01

Download DiskLoomSetup-x64.exe from the latest release.

02

Run the Windows installer. It installs the desktop app and adds dlm to PATH.

03

Use DiskLoom visually, or run dlm C:\Users --csv users.csv from a terminal.
