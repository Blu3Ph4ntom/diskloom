Open-source Windows disk analyzer

See your disk clearly.

DiskLoom is a Rust-native disk space analyzer for Windows, built for direct NTFS MFT scanning, low memory use, responsive browsing, and fast cleanup decisions.

Download for Windows View source

Built to challenge WizTree. DiskLoom will not claim benchmark wins until reproducible public data proves them. No telemetry. No background service.

Fast where it matters.

Direct NTFS path

Reads NTFS metadata directly for drive scans when Windows allows raw volume access.

Fallback traversal

Scans folders and non-NTFS locations without admin access, with allocated size reporting on Windows.

Compact graph

Uses integer IDs, string interning, parent links, and lazy paths instead of storing full paths per file.

Clean deletion flow

Find large files quickly, inspect the tree, open in Explorer, and delete to Recycle Bin from the app.

CLI included

Run dlm from a terminal to scan the current folder, export CSV, or list largest entries.

Benchmark-ready

Includes benchmark harnesses for scan time, memory, responsiveness, export speed, and public claim comparison.

Install once. Use app or CLI.

01

Download DiskLoomSetup-x64.exe from the latest GitHub release.

02

Run the Windows installer. It installs the GUI and adds dlm to PATH.

03

Open DiskLoom for cleanup, or run dlm in any terminal for quick scans and CSV export.
